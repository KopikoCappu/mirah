Privacy policy

Last updated: September 27, 2026

Mirah is a personal tool used only by its owner to sort their own email. It is not offered to the public.

What data Mirah accesses

With the account owner's permission, Mirah reads messages in the connected Gmail and Outlook inboxes: sender, recipients, subject, date, and message body. It can add labels (Gmail) or categories (Outlook) to messages. It never sends, deletes, or archives email.

How the data is used

  • Each new message's sender, subject, and the first part of its body are sent to TypeSafe's Jev classification API to decide whether the message is important, needs review, or is junk.
  • Mirah stores a short record of each sorted message (sender, subject, a short snippet, the classification, and a link back to the message) in Google Cloud Firestore, so the owner can review it. Full message bodies are not stored.
  • Access tokens for the connected accounts are stored encrypted and are used only to read and label mail.

Sharing

Data is not sold, shared, or used for advertising. It is processed only by the services listed above (Google Cloud, TypeSafe) to provide the sorting feature.

Google API Services User Data Policy

Mirah's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Mirah's settings page, from Google Account permissions, or from Microsoft account permissions. Stored records can be deleted on request.
